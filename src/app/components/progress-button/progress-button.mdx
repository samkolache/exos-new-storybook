## Usage

Use it to take people to a list of tasks, like reviewing every part of an interior. It is built for dark surfaces: the fill is see-through and the text is white.

```html
<app-progress-button label="Review interior" [completed]="3" [total]="8" (clicked)="open()" />
```

## Variations

<Variation title="Status" of={ProgressButtonStories.Statuses}>

The colour follows `completed` and `total`. You don't set it yourself:

- **Pending** (blue): nothing done yet, `completed` is 0.
- **In progress** (yellow): some done.
- **Complete** (green): `completed` equals `total`.

</Variation>
