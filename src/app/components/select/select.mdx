<Subtitle>A select lets people pick one option from a longer list, shown only when they open it.</Subtitle>

## Live demo

One form, one piece of code. On a phone, tapping the field opens the phone's own picker; on the web, a list drops down.

<DeviceCanvas of={SelectStories.Overview} defaultDevice="mobile" />

## When to use

**Use a select** when people pick **one** option from a list that's too long to show all at once:

- 6 or more options, like countries, time zones or sort orders.
- A known list people mostly recognise, so they don't need to compare every option.
- Space is tight, like a toolbar or a dense form.

### Compared with look-alikes

| Component | Options | All visible | People pick |
|---|---|---|---|
| **Select** | 6 or more | No, in a list | One |
| [Radio group](?path=/docs/components-forms-radio-group--docs) | 2–5 | Yes | One |
| [Chip](?path=/docs/components-chip--docs) | 2–7, short | Yes | One or several |
| [Checkbox](?path=/docs/components-forms-checkbox--docs) | Any | Yes | Any number |
| [Dropdown](?path=/docs/components-dropdown--docs) | Actions | No, in a menu | Does something now, not a form value |

With 2 to 5 options, show them: radios or chips are one tap instead of two.

## Anatomy

<DeviceCanvas of={SelectStories.Anatomy} noCode />

| # | Part | Shows when |
|---|---|---|
| 1 | **Label** | Always. A red `*` when required, or "(optional)". Hide it on screen only with `hideLabel`. |
| 2 | **Field** | Always. Shows the picked option, or the placeholder. |
| 3 | **Chevron** | Always, except read only. With a status icon beside it for warning, invalid and valid. |
| 4 | **Help text and message** | `helpText`, or a `state` with `feedback`. |

## Size

<DeviceVariation title="Small, medium, large" of={SelectStories.Switchable} sizeSwitch>

Use the switch in the toolbar. Only `size` changes in the code. The same heights as [Input](?path=/docs/components-forms-input--docs), so they line up in a row.

- **Small** (`sm`, 32px): toolbars, tables and filters.
- **Medium** (`md`, 40px, default): most forms.
- **Large** (`lg`, 48px): short forms where picking is the main task.

On phones fields are **48px** tall (**44px** small) with **16px** text. Switch the toolbar to Mobile to see it.

</DeviceVariation>

## Modifiers

<DeviceVariation title="Placeholder" of={SelectStories.ModPlaceholder}>

`placeholder` shows while nothing is picked, like "Choose a country". It can't be picked itself, so a required select can't be sent empty by accident. Set `placeholder=""` when there's always a sensible answer, like a sort order.

</DeviceVariation>

<DeviceVariation title="Groups" of={SelectStories.ModGroups}>

Add `group` to options to list them under headings, like regions for time zones. Use it past about 10 options, when the headings help people find their way.

</DeviceVariation>

<DeviceVariation title="Help text" of={SelectStories.ModHelp}>

`helpText` for what people need to know before they pick, like what the answer is used for.

</DeviceVariation>

<DeviceVariation title="Optional" of={SelectStories.ModOptional}>

`[optional]="true"` shows "(optional)". Mark the few optional fields rather than every required one.

</DeviceVariation>

<DeviceVariation title="Hidden label" of={SelectStories.ModHiddenLabel}>

`[hideLabel]="true"` when the options explain themselves, like a sort control in a toolbar. The label is still read by screen readers.

</DeviceVariation>

<DeviceVariation title="Floating label" of={SelectStories.ModFloating}>

`[floatingLabel]="true"` puts the label inside the field, to save height in short forms. Use it with the inputs around it, not on its own.

</DeviceVariation>

## Specs

Use **Small / Medium / Large**, **Help / Error** and **Mobile / Web** to see each case. Blue shows the padding inside the field. The numbers are measured from the code.

<SpecPictures of={SelectStories.SpecDrawing} />

- **Label to field:** 8px on every device.
- **Field to help or error text:** 4px on the web, 8px on phones, so the message reads as its own line under a taller field.
- **Help text** is grey and **error text** is red, both 14px. An error shows right under the field (above any help text), and the field gets a red border.
- Phone text is 16px or more, so the phone doesn't zoom in. Phones open their own option list.

## Content

- **Labels** are short nouns: "Country", "Time zone".
- **Placeholders** say what to do: "Choose a country". Not "Select…" on its own.
- **Order options so they're easy to find:** alphabetical for names, in order for sizes or times, most common first only when one or two answers cover most people.
- **Keep option labels short.** The field shows only as much as fits.

<DoDont>
  <Guideline type="do" of={SelectStories.DoManyOptions}>use a select for long lists.</Guideline>
  <Guideline type="dont" of={SelectStories.DontFewOptions}>hide 2 or 3 options in a select.</Guideline>
  <Guideline type="do" of={SelectStories.DoFewAsRadios}>show a few options as radios or chips: one tap instead of two.</Guideline>
  <Guideline type="dont" of={SelectStories.DontPreselectFirst}>preselect the first option. People miss it and send it unchanged.</Guideline>
  <Guideline type="do" of={SelectStories.DoGroupLong}>group long lists under headings.</Guideline>
  <Guideline type="dont" of={SelectStories.DontLongLabels}>write sentences as options. They get cut off in the field.</Guideline>
</DoDont>

## States

<DeviceVariation title="All states" of={SelectStories.AllStates} noCode>

- **Warning:** allowed, but worth a second look.
- **Invalid:** has to be fixed before the form is sent.
- **Valid:** only when confirming helps.
- **Read only:** no chevron, since it won't open. People can Tab to it and read it.
- **Disabled:** can't be used right now, and is skipped by <kbd>Tab</kbd>. Say nearby why.

Status messages lead with an icon in the field, so colour is never the only signal.

</DeviceVariation>

## Behavior

### Keyboard

| Key | Does |
|---|---|
| <kbd>Tab</kbd> | To the select and on to the next field |
| <kbd>Space</kbd> / <kbd>Enter</kbd> / <kbd>Alt</kbd> <kbd>↓</kbd> | Opens the list |
| <kbd>↑</kbd> <kbd>↓</kbd> | Next or previous option |
| Letters | Jumps to the first option starting with them |
| <kbd>Esc</kbd> | Closes the list without changing the answer |

### Mobile and web

| | Mobile (below 672px) | Web (672px and up) |
|---|---|---|
| Space to help or error text | 8px | 4px |
| Label to field | 8px | 8px |
| Opens | The phone's own picker, at the bottom of the screen | A list under the field |
| Height | 44 / 48 / 48px (small / medium / large) | 32 / 40 / 48px |
| Text | 16px, so the phone doesn't zoom in on focus | 14 to 16px, by size |
| Many options | Fine: the picker scrolls and people can flick through | Fine: people can type to jump |
| Layout | One column, full width | On the grid, sized to the answer |

See [Mobile and web](?path=/docs/foundations-mobile-and-web--docs) for the rules every component follows.

### Edge cases

<SpecimenGrid>
  <Specimen of={SelectStories.EdgeLongOption}>**Long option:** the field shows what fits; the list shows it all. Shorten it if you can.</Specimen>
  <Specimen of={SelectStories.EdgeDisabledOption}>**Unavailable option:** add `disabled: true` and say why in the label.</Specimen>
  <Specimen of={SelectStories.EdgeOneOption}>**One option:** show it as text instead; there's nothing to pick.</Specimen>
</SpecimenGrid>

## Accessibility

For the invalid playground, a screen reader reads:

<ScreenReader name="Country" role="combo box" state="collapsed, required, invalid entry" description="Choose the country you’re shipping to." />

- **It's the browser's own select,** so every screen reader, keyboard and phone already knows how to use it.
- **Labels:** every select has a `<label>`, even with `hideLabel`.
- **Messages and help text** are linked with `aria-describedby`, so they're read when people reach it.
- **Read only** uses `aria-readonly`, and keys and clicks can't change it.
- **Checked automatically:** every select story runs an accessibility scan in the tests, and a test checks the text above.
