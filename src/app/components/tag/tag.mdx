## Usage

Tags are read-only. If people should click or pick something, use a [Chip](?path=/docs/components-chip--docs) or [Button](?path=/docs/components-button--docs) instead.

```html
<app-tag label="From order" icon="calendar" />
```

## Variations

<Variation title="Color" of={TagStories.Colors}>

Set the `color` input to match the meaning:

- `neutral` (default) for plain facts, like "From order".
- `blue` for AI. Usually set with `ai` instead (see below).
- `attention` for things that need someone, like "Needs your input".
- `info` for things in progress, like "Waiting on photo".

</Variation>

<Variation title="Icon" of={TagStories.Icons}>

Add an `icon` to make the tag quicker to scan. Leave it out (`none`, the default) for text-only tags.

</Variation>

<Variation title="AI" of={TagStories.ExampleAITags}>

Add `[ai]="true"` when the AI produced the answer. The tag turns blue with a sparkle. Pass an `icon` to replace the sparkle, like `icon="voice"` for voice notes.

</Variation>

<Variation title="Disabled" of={TagStories.ExampleDisabledTags}>

Add `[disabled]="true"` for things nobody needs to act on, like skipped steps. It greys out the tag and its icon, whatever the color.

</Variation>

<Variation title="Size" of={TagStories.Sizes}>

Use the `size` input: `sm`, `md` (default) or `lg`.

</Variation>

<Variation title="Figma source tags" of={TagStories.ExampleFigmaSourceTags}>

The full "Review / Source tag" set from Figma, built from these inputs. Show the code to copy any of them.

</Variation>
