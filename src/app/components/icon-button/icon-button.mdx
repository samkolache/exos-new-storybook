## Usage

Use an icon button when the icon alone makes the action clear. If it might not be clear, use a [Button](?path=/docs/components-button--docs) with a label.

```ts
import { LucideChevronLeft } from '@lucide/angular';
```

```html
<app-icon-button [icon]="LucideChevronLeft" label="Back" (clicked)="goBack()" />
```

## Variations

<Variation title="Variant" of={IconButtonStories.Variants}>

Set the look with the `variant` input:

- `light` (default) is frosted white with a soft shadow.
- `primary` matches the primary [Button](?path=/docs/components-button--docs): dark fill, white icon.
- `ghost` has no background or border, just the icon. Use it where a filled circle would be too heavy.
- `glass` is see-through white with a white icon, for dark or photo backgrounds. Its icon is smaller (14px).

</Variation>

<Variation title="Icon" of={IconButtonStories.Icons}>

Pass any [Lucide](https://lucide.dev/icons/) icon to the `icon` input. Icons render at 18px (14px for `glass`).

</Variation>

<Variation title="Accessible label" of={IconButtonStories.AccessibleLabel}>

The button has no visible text, so `label` is required. Screen readers announce it as the button's name, so describe the action ("Back"), not the icon ("Chevron").

</Variation>
