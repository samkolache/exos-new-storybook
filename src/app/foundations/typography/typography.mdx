# Typography

**Raleway for the big moments. Geist for everything else.** Raleway carries the brand voice in a few large headlines; Geist carries reading, UI and numbers; Geist Mono carries eyebrows and codes.

Source: Figma "Sams Vibe", Typography · Final, with three changes for the web (see [Changes from Figma](#changes-from-figma)).

## Live demo

A Raleway headline anchors the view; Geist does the work. Sizes are the same on phones and the web.

## Families

Three families, one job each.

| Family | Used for | Weights |
|---|---|---|
| **Raleway** | Display and Heading L only. 24px and up | Medium 500 · SemiBold 600 · **Bold 700 (default)** |
| **Geist** | Headings M and S, body, labels, numbers | Regular 400 · Medium 500 · SemiBold 600 |
| **Geist Mono** | Eyebrows and codes. Uppercase eyebrows only | Medium 500 |

## Type styles

Each style is a class, measured live from the theme. HTML headings use them too: `<h1>` is Heading L, `<h2>` is Heading M, and `<h3>`–`<h6>` are Heading S. Display styles are classes only, for the one hero per view.

### Changes from Figma

| Style | Figma | Exos | Why |
|---|---|---|---|
| Body L | 15 / 24 | **16 / 24** | 16px is the web standard for reading, and text in a field under 16px makes phones zoom in when it gets focus |
| Display M | 32 / 36 | **32 / 40** | 36 is 1.13×: when a headline wraps, the two lines nearly touch |
| Eyebrow S | 10 / 12 | **11 / 12** | 11px is the smallest text that stays readable, and capitals at 10px blur together |

Everything else matches Figma.

## Line height and letter spacing

Line height sits on the 4px grid and tightens as size grows. Letter spacing goes negative as size grows, and positive for small and uppercase text.

| Tier | Sizes | Line height | Letter spacing | Why |
|---|---|---|---|---|
| Display (Raleway) | 30–34 | 1.18–1.25× | −1.5% to −2% | Large type looks loose; tighten it so it holds as one shape |
| Heading L (Raleway) | 24 | 1.33× | −1% | Still large; a slight pull-in keeps Raleway compact |
| Heading M/S (Geist) | 15–20 | 1.33–1.4× | −0.5% to 0 | Neutral at reading sizes |
| Numbers (Geist) | 20–34 | 1.18–1.4× | −1% to −2% | Tabular figures, tight so values read as one unit |
| Body (Geist) | 13–16 | 1.43–1.54× | 0 | Room between lines for comfortable reading |
| Caption, Label S | 12 | 1.33× | +0.5% to +1% | Small text needs a little air to stay legible |
| Labels L/M | 15–16 | 1.25–1.33× | 0 | Single line; a tight box keeps buttons compact |
| Eyebrow (Geist Mono, uppercase) | 11 | 1.1–1.45× | +8% | Capitals crowd; open them up |

- **Line heights are unitless in the CSS,** so they grow with the text when people make it bigger.
- **Letter spacing is in em, not px.** Figma stores it in px (−0.68px at 34px); em is the same percentage and scales with the text.

## Weight

| Where | Weight | Why |
|---|---|---|
| Body text | **400** | Never lighter: thin strokes break up at small sizes and on low-quality screens |
| Emphasis inside a sentence | **500** | 600 and up pulls the eye too hard at 13–16px |
| Headings M and S, labels, numbers | **600** | Small headings need weight to stand apart from 400 body text at nearly the same size |
| Raleway display and Heading L | **700 by default** | The brand voice. Large type carries the hierarchy, so a calmer weight also works |
| Eyebrows and code | **500** | Capitals are already loud; the extra spacing does the work |

Raleway has two calmer weights for display and Heading L. Add `.exos-type-semibold` for calmer or longer headlines, or `.exos-type-medium` for quiet, editorial ones.

<DeviceCanvas of={Stories.RalewayWeights} defaultDevice="web" noCode />

Best practices:

- **Two or three weights per family.** Hierarchy reads best when weights are at least 200 apart, like 400 and 600. Steps of 100 look like mistakes.
- **Never use Raleway Light, Regular or Black, or any Geist weight above SemiBold.**
- **Light text on a dark fill looks heavier,** so it can drop one step, for example on a dark button.
- **Only the weights above are loaded.** A weight that isn't loaded is faked by the browser and looks smudged. Raleway ExtraBold (800) is in Figma for marketing heroes only; it isn't loaded in the product.

## Rules

  <Guideline type="dont" of={Stories.DontSmallRaleway}>use Raleway below 24px, or in buttons, labels, tables or body text.</Guideline>
  <Guideline type="do" of={Stories.DoLevels}>pick the tag for the structure, and the class for the look.</Guideline>
  <Guideline type="dont" of={Stories.DontLevels}>skip heading levels to get a smaller size.</Guideline>
  <Guideline type="do" of={Stories.DoEyebrowCaps}>use capitals only in eyebrows and codes.</Guideline>
  <Guideline type="dont" of={Stories.DontCaps}>set headings, buttons or labels in capitals or Title Case.</Guideline>
  <Guideline type="do" of={Stories.DoStyles}>always apply a type style.</Guideline>
  <Guideline type="dont" of={Stories.DontByHand}>set size, line height or letter spacing by hand.</Guideline>

- **Sentence case** for headings, buttons and labels: "Open claims", not "Open Claims".
- **Don't mix Raleway and Geist in the same line.**
- **Body text is 13px or more,** with 45–75 characters a line. Add `.exos-measure` (66ch) to long paragraphs.
- **Keep headings short,** ideally one line on a phone, with no full stop.
- **Use a Number style for figures,** so digits line up and don't jump when they change.

## Accessibility

- **Headings follow the page structure.** One `h1` per page, then `h2`, `h3` and so on, without skipping levels. Screen reader users jump from heading to heading. Use the `.exos-*` classes to change how a heading looks.
- **Sizes are in rem,** so text grows when people change their browser or phone text size.
- **Body text is 16px for reading and in fields,** and never under 13px. 11px is only for eyebrows, badges and tags.
- **Contrast:** text reaches 4.5:1 against its background, and large headings 3:1 or more (WCAG AA). Use the text colour tokens (see [Colors](?path=/docs/foundations-colors--docs)).
- **Checked automatically:** every typography story runs an accessibility scan, and a test checks which styles use which family.

## Code

### Usage

Use plain HTML and Bootstrap, plus a type class where the tag's default isn't the right look.

```html
<p class="exos-eyebrow-m">Total balance</p>
<p class="exos-number-l">$12,480.32</p>
<h1 class="exos-display-m">Plan your week</h1>   <!-- the one hero: Raleway -->
<h2>This week</h2>                                <!-- Heading M: Geist -->
<h3>Trip to Kyoto</h3>                            <!-- Heading S: Geist -->
<p class="exos-body-s">Card expired. Update and retry.</p>
<p class="exos-code">INV-1042</p>
```

In component SCSS, `@include exos-type("label-m")` sets the family, size, line height, letter spacing, weight and case at once. In plain CSS, use the variables:

```css
.photo-caption {
  font-size: var(--exos-type-caption-size);
  line-height: var(--exos-type-caption-line-height);
  letter-spacing: var(--exos-type-caption-tracking);
}
```

### Theming

Every style has four variables on `.exos-theme-dcfc`: `--exos-type-<style>-size`, `-line-height`, `-tracking` and `-weight`, with `<style>` one of `display-l`, `display-m`, `display-s`, `heading-l`, `heading-m`, `heading-s`, `number-l`, `number-m`, `number-s`, `body-l`, `body-m`, `body-s`, `caption`, `label-l`, `label-m`, `label-s`, `eyebrow-m`, `eyebrow-s` or `code`.
