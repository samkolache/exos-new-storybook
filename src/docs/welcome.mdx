## Use a component

Components are standalone. Import the one you need and use it in your template:

```ts
import { Component } from '@angular/core';
import { ChipComponent, ChipOption } from './components/chip/chip';

@Component({
  selector: 'app-example',
  imports: [ChipComponent],
  template: `<app-chip groupLabel="Interior condition" [options]="options" [(value)]="condition" />`,
})
export class ExampleComponent {
  options: ChipOption[] = [
    { label: 'Good', value: 'good' },
    { label: 'Average', value: 'average', suggested: true },
    { label: 'Fair', value: 'fair' },
  ];
  condition = 'average';
}
```

Every docs page has **Show code** under each example. It gives you a complete component like this one, and it follows the controls, so you can set things up in the demo and copy the result.

## Theme

The styles come from one entry point, `src/styles.scss`, which compiles Bootstrap 5.3 with the Exos tokens. The tokens' CSS variables are scoped to the `exos-theme-dcfc` class, so put it on a parent element (the app puts it on `<body>`):

```html
<body class="exos-theme-dcfc">
  <app-root></app-root>
</body>
```

Colors live in `src/theme/scss/tokens/`: raw values in `_primitives.scss` and their meanings (like `text-heading` or `border-focus`) in `_colors.scss`. Components only use the meanings.
